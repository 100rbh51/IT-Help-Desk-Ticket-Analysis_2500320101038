
# P4 – Dataset Selection

## Selected Dataset

Help Desk Tickets

## Source

Mendeley Data, Version 3
DOI: 10.17632/btm76zndnt.3
Dataset page: https://data.mendeley.com/datasets/btm76zndnt/3
Contributor: Mohammad Abdellatif
License: CC BY 4.0

## Dataset Description

The dataset contains help desk ticket records and related workflow information. The source describes records from January 2007 to March 2023. Some fields have been masked to protect the data provider's privacy.

## Files Selected for This Project

- `data/raw/issues.csv` — main ticket records
- `data/raw/FEATURES.md` — field descriptions

Other files from the download are not included in the current analysis scope.

## Why This Dataset Was Selected

The columns include ticket type, priority, status, created and resolution dates, and workflow timing fields. These can support descriptive analysis of ticket volume, ticket categories, priority, status, and resolution time, subject to validation of the field definitions and data quality.

## Limitations

- The data is masked and comes from one help desk context; findings should not be generalized to every organization.
- The dataset has not yet been cleaned or analyzed.
- Final metrics will depend on field definitions and data-quality checks.
- The dataset is licensed under CC BY 4.0; attribution to the contributor and source must be retained.
