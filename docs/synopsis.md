
# P2 – Project Synopsis

## Project Title

IT Help Desk Ticket Analysis

## Introduction

Organizations use IT help desks to record and resolve employee issues such as software, hardware, account, and network problems. This project will analyze help desk ticket data to understand ticket volume, issue categories, priorities, statuses, and resolution times, depending on the fields available in the selected dataset.

## Problem

Without reviewing ticket records systematically, it can be difficult to identify common issues, workload patterns, and delays in resolution. This project will use data analysis and visual reporting to make those patterns easier to understand.

## Objectives

- Select a public, synthetic, or otherwise authorized dataset.
- Document dataset fields and limitations.
- Clean and validate the data using Python.
- Analyze supported measures using Python and SQL.
- Present findings through charts, Excel, and a Power BI report.
- Document the process, testing, findings, and limitations.

## Proposed Tools

- Python: data cleaning and analysis
- SQL: data storage and querying
- Jupyter Notebook: exploratory analysis
- Excel: supplementary analysis and reporting
- Power BI: interactive dashboard
- Streamlit: optional project interface
- GitHub: version control and project documentation

## Scope

The project will focus on descriptive analysis of the selected help desk ticket dataset. It will not use confidential organizational data without permission. Predictive modeling and production ticket-management features are outside the current scope.

## Expected Outcome

A documented analytics project containing a prepared dataset, reproducible code and queries, charts, and a dashboard that summarizes patterns supported by the selected data. Any recommendations will be based on the analysis and will include relevant limitations.

## Dataset Status

The dataset has not yet been selected or analyzed. The available fields, time period, and final metrics will be confirmed during dataset selection and data dictionary preparation.

## Limitations

The analysis will depend on the completeness and quality of the selected dataset. It may not be possible to calculate every planned metric if required fields, such as ticket creation or resolution timestamps, are missing.
